# Workstrand for VS Code

Install this folder as a VS Code extension, set `kestrel.acpExecutable` if `kestrel-acp` is not on `PATH`, then run **Workstrand: Start Task**. The extension opens a persistent Workstrand output stream, displays native modal approvals, delegates contained file reads/writes through `workspace.fs`, and embeds captured argv-only commands as VS Code pseudoterminals.
