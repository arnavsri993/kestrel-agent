# Kestrel for JetBrains IDEs

Build with `gradle buildPlugin`, install the generated ZIP from disk, and open the **Kestrel** tool window. Set `KESTREL_ACP_PATH` when `kestrel-acp` is not on `PATH`. The plugin targets IntelliJ Platform 2026.1 (build 261), uses the current 2.x Gradle plugin, and provides streaming tasks, native approval dialogs, contained project file delegation, and captured argv-only terminal work.
