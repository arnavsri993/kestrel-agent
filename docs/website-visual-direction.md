# Website visual direction

The public site explains a general autonomous agent through a single signal progressing from observation to verified outcome. Generated media, when approved, supplies only abstract atmosphere. Every readable interface, decision, evidence item, control, and status is deterministic React/HTML.

The first viewport is an asymmetric editorial composition: Kestrel and the supplied headline on the left, one operational canvas on the right, joined by the acid-yellow signal thread. The teacher workflow is the main proof; DJI context shows the value of memory; a compact task spectrum demonstrates unfamiliar work without marketing a bundle of mini-apps.

Video editing is not a section, navigation item, pricing tier, or architecture claim. Media work may appear once in the task spectrum as one example of choosing available tools.

Download and GitHub controls must report their real availability. Until a signed/notarized release and repository URL exist, the site shows an explicit release-readiness state rather than a false download.
