# Memory system

Kestrel separates episodic, semantic, procedural, project, relationship, and short-lived working memory. Retrieval combines exact entities, keywords, temporal validity, importance, confidence, recency, and optional semantic similarity.

`PreResponseContextResolver` first predicts which categories could materially change an answer, then retrieves a small bounded set. It labels confirmed facts, inferences, and possibly stale facts separately. Contradictions preserve both records; newer or user-confirmed facts rank higher, while consequential conflicts require clarification.

The DJI fixture is the acceptance case: known charging and app-launch behavior, a second cable test, a failed restart, and an iOS developer beta must move software compatibility above generic cable advice.
