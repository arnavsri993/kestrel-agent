# OpenClaw, Hermes, Codex, and Claude Code parity

Kestrel's target is the union of the useful capabilities in all four reference products, implemented behind Kestrel's local-first privacy, approval, audit, and idempotency boundaries. This rolling engineering catalog records implemented capability families; it is not a claim of universal product superiority.

Source snapshot: **2026-07-23**. The refresh used GitHub's complete, non-truncated tree API and inspected 750 OpenClaw Markdown/MDX pages at upstream commit `f9708083f837d5397661a7388bc61cdc3b55daed` plus 367 Hermes pages at commit `4c9628eab5393e7561bbd2c1faaa1765fb14a5f9`. The immutable page path, Git blob SHA, source URL, capability mappings, coverage class, and known-gap ID for all 1,117 pages are stored in [`reference-page-audit.json`](reference-page-audit.json) and checked by `pnpm audit:references`. The verifier also requires these prose and catalog commit pins to match the machine audit, so provenance drift fails CI.

## Status definition

- **Implemented**: works end to end in the current development app and is covered by repository evidence.
- **Partial**: a tested foundation or narrow vertical slice exists, but the reference-product behavior is not complete.
- **Planned**: no honest runtime implementation exists yet. UI copy must not present it as available.

Current catalog: **58 capability families — 58 implemented, 0 partial, 0 planned**.

That family-level result is not treated as proof that every reference page is complete. The page-level snapshot classifies 588 pages as implemented core-family evidence, 375 vendor-specific pages as supported through the signed extension contract, and 154 as operational/reference material, with zero known unmapped pages. Native-node pages map to the tested paired-node extension protocol; they do not imply that Kestrel ships a mobile application.

Product abbreviations: O = OpenClaw, H = Hermes Agent, C = Codex, A = Claude Code.
